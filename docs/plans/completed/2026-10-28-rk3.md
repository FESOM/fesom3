## Overview

Add the three-stage Wicker–Skamarock Runge–Kutta (RK3) ocean step of Sergey Danilov's quad FV prototype to FESOM3,
as an alternative to the AB2 step:

    φ*   = φⁿ + τ/3·F(φⁿ)
    φ**  = φⁿ + τ/2·F(φ*)
    φⁿ⁺¹ = φⁿ + τ·F(φ**)                      (self-starting, no AB history)

- **Cheap stages 1 and 2:** tracers get advection only; momentum gets advection, Coriolis and the pressure gradient
  (with −g∇ηⁿ). Both advect with the full w of the stage, as `rk3.tex` does (wⁿ, w^{n+1/3}): there is no w split
  before stage 3, so a uniform tracer stays uniform in every stage. Everything else is done once, in stage 3:
  viscosity, vertical mixing, diffusion, GM/Redi, surface fluxes, wind and drag, the FCT limiter and the w split
  (explicit w_e, implicit w_i).
- **Two barotropic versions** (both in this plan, CG first):
  - semi-implicit CG: the stage-3 corrector, reusing FESOM3's SSH solve;
  - split-explicit (SE): the existing Shchepetkin–McWilliams AB3–AM4 substeps, fed by an RK3 BC→BT forcing.
- **FCT only in stage 3, with the w split in its low order only.** The first-order low-order (LO) solution lies
  outside the RK3 stages. The split (explicit w_e below the cap, then implicit w_i) makes its vertical part stable at
  any vertical Courant number, so only the horizontal part keeps a Courant limit. Hence one LO step (N = 1, today's
  LO) is the default, and N = 2 or 3 substeps with consistent intermediate thicknesses are an option for a
  horizontal LO Courant number near 1.
- **Why:** RK3 is more accurate and more stable than AB2. Sergey's expectation is that the model runs with about
  twice the current Δt, which raises throughput although an RK3 step costs more than an AB2 step. Measured, not
  assumed.
- **Scope:** linfs first (production), then zstar (Stage 6).
- **Default unchanged:** with `FESOM3_RK3` unset, the outputs are **byte-identical** to frozen main references (G0).
- **Not bitwise to AB2.** RK3 is judged by exact unit identities, per-step invariants, determinism, restart
  exactness, and CORE2 screens and twins.

## Context (from discovery)

### The reference: `~/qq_new2` and `rk3.tex`
- `oce_timestep_RK3_SE` (`oce_stepRK3_SE.F90:1-59`) is the reference run (`bin/fvom.ou`: Soufflet channel, dt = 2400 s,
  5 years, stable). `oce_timestep_RK3` (`oce_stepRK3.F90:9-64`) is the CG version. Both are linfs.
- **Per stage:** `vert_vel_RK3(u_s)` (`Vf`, `Wvel` = w·area), then `solve_tracers_RK3(s)`, then `pressure_RK3`, then
  `vel_rhs_RK3` (`u_s = uⁿ + R − ⟨R⟩`: trim to the barotropic (BT) transport at n).
- **Stage 1 (SE only):** `bh_viscosity_RK3` (from uⁿ, kept in `U_visc`) and `BC2BT_forcing`.
- **Stage 3:** `pressure_bv_RK3(T**)`, PP mixing from uⁿ and N²(T\*\*), then `vert_vel_RK3(u**)`. Then the barotropic
  step:
  - SE: `BT_SESM_RK3` (`BTsteps = 90` and `aSM = 0.1` hard-coded) and `vel_rhs_RK33_SE`, which does R(u\*\*) + `U_visc`
    and `impl_vert_visc_SE_1`, trims u\*\* to `UBTmean` and uⁿ⁺¹ to `UBT`;
  - CG: `vel_rhs_RK33`, `compute_ssh_rhs` and `solve_ssh`, then `update_vel_RK3` (θ = 1, u\*\* trimmed to Σh·uⁿ⁺¹).

  Then `vert_vel_RK3(u** trimmed)` and `solve_tracers_RK3(3)`: advection, then `t_ver_diff_impl_RK3` (the surface
  fluxes in its first row).
- **Prototype quirks**, handled as follows:
  - `U_rhsBC` is first order (at n) and is kept (Post-Completion question).
  - The Soufflet `friction = -0.005` and `Av = 1e-4` are not ported; FESOM3 uses its own C_d drag and mixing.
  - Stage 2 uses p(T\*\*); replaced by the textbook p(T\*) (D3).
  - The metric term at n is not relevant: FESOM3's operators are used.
  - `eta_n` = η^{n+1} inside stage 3; made explicit here: stage 3 uses ηⁿ, and η is committed after it.
  - qq has no shared-element sync; added here (L70).
  - `vel_rhs_RK32`'s double /H is not ported (that routine is unused).
- **`rk3.tex`** (repo root, untracked; Sergey's algorithm text):
  - the z\* version with stage thicknesses h^{n+1/3}, h^{n+1/2} and the trimming formulas;
  - the SE "first stage" strategy (the BC→BT forcing from n, the BT solve once);
  - stage 3 = viscosity, the vertical TDMAs, the surface forcing;
  - every stage diagnoses its own full w (wⁿ, w^{n+1/3}, and w^{n+1/2} updated after the trim) and advects with it.
    `rk3.tex` has no w split; FESOM3 adds one in stage 3 only (D7).

  The NEMO / Oceananigans "dagger velocity" variants at its end are **not** in scope.

### Tracers
- `solve_tracers_ale` (`oce_ale_tracer.F90:98-211`):
  - the GM bolus is added to `uv`, `w` and `w_e`;

  - `oce_tra_adv_fct`, then `flux2dtracer(use_lo)`.

## Technical Details

### 1. Notation, arrays, halo extents
- τ = Δt, τ₁ = τ/3, τ₂ = τ/2, τ₃ = τ. ⟨X⟩_e = Σₖ helemₖ,e·Xₖ,e / H_e with H_e = `rk3_H(e)` = Σₖ helemₖ,e
  (ulevels..nlevels−1). `rk3_H` is rebuilt at the start of every step (under zstar per stage). Under SE it equals
  `se_H`; it is kept separate because CG has no `se_H`. I(·) = the inflow edge scatter (positive = convergence), as
  `compute_hbar_ale`/`se_inflow`.
- **During a step:**
  - `dyn%uv` = uⁿ until the final update; `rk3_us` = u\*, then u\*\* (owned + eDim halo, as uv);
  - `values` = Tⁿ; `valuesAB` = the stage tracer (T\*, T\*\*; owned + halo);
  - `rk3_visc` = the viscous increment of uⁿ over τ;
  - `w_e`, `w_i`: in stages 1–2 `w_e` = w and `w_i` = 0 (the split off); in stage 3 the split of the stage-3 w, made
    by `vert_vel_ale` (owned + halo faces), as in AB2.
- `uv_rhsAB` is scratch under RK3: `compute_vel_rhs` writes Coriolis + advection into it. `valuesold` is not rolled.
  Neither is state under RK3 (cold AB start, D11).

### 2. One step (linfs)

    rk3_H = Σ helem                                         ! every step (restart-safe)
    ! stage 1 (τ/3)
    vert_vel_ale(τ, split=.false., bolus=.false.)          ! full w from uⁿ: w_e = w, w_i = 0
    pressure_bv(Tⁿ, pressure_only) + PGF
    rk3_tracer_stage(1, τ/3)                                ! valuesAB: Tⁿ → T*
    rk3_viscosity                                           ! rk3_visc from uⁿ
    compute_vel_rhs(τ/3, no_history)                        ! R¹ in uv_rhs
    [SE] se_bt_forcing_rk3(τ); se_subcycle(τ)               ! se_elem_depth first; η^M, U^M, ⟨⟨U⟩⟩ (not committed)
    rk3_us = uⁿ + R¹ − ⟨R¹⟩; sync; exchange
    ! stage 2 (τ/2)
    vert_vel_ale(uv_in=rk3_us, split/bolus off)             ! full w from u*: w_e = w, w_i = 0
    pressure_bv(T*, pressure_only) + PGF                    ! textbook p(T*), before T* is overwritten
    rk3_tracer_stage(2, τ/2)                                ! valuesAB: T* → T**
    compute_vel_rhs(τ/2, uv_in=rk3_us, no_history)          ! R²(u*)
    rk3_us = uⁿ + R² − ⟨R²⟩; sync; exchange
    ! stage 3 (τ)
    pressure_bv(T**) full + PGF                             ! [dump pressure]
    sw_alpha_beta (KPP|GM|Redi); sigma_xy, slopes (GM|Redi) ! from T**, as step_oce:169-180
    compute_vel_nodes (uⁿ); compute_shear2; PP|KPP|TKE; mo_convect   ! [dump Kv]
    vert_vel_ale(uv_in=rk3_us, bolus off)                   ! w from the untrimmed u**; split on: w_e, w_i
    compute_vel_rhs(τ, uv_in=rk3_us, no_history); uv_rhs += rk3_visc   ! advection with w_e
    impl_vert_visc_ale(τ)                                   ! base uⁿ, w_i, wind, C_d drag
    [CG] update_stiff_mat_ale (not linfs); compute_ssh_rhs_ale; solve_ssh_ale; update_vel;
         compute_hbar_ale; update_eta_n                     ! [dumps ssh_rhs, d_eta, hbar, eta_n]
         rk3_trim(rk3_us → Σh·uⁿ⁺¹)
    [SE] se_rk3_finish                                      ! uⁿ⁺¹ → U^M, u** → ⟨⟨U⟩⟩, commit η [dumps hbar, eta_n]
    init_Redi_GM / fer_solve_Gamma / fer_gamma2vel          ! from bvfreq(T**)
    vert_vel_ale(uv_in=rk3_us, bolus on)                    ! split on [dump ALE]
    solve_tracers_rk3(τ)                                    ! per tracer rk3_tracer_prep, advection (FCT: the
                                                            ! split LO), diffusion, TDMA (non-FCT: w_i); Redi Ki
                                                            ! switch; clamp [dumps T, S]
    update_thickness_ale                                    ! [dump hnode]
    [SE + SE_CHECK] se_check_tail;  [RK3_CHECK] rk3_check (+ TOL stop)

The step uses three `vert_vel_ale` calls for the stages and one more in stage 3 for the trimmed transport, three
pressure calls (two pressure-only) and three momentum right-hand sides.

### 3. The CG block (stage 3)
- With `uv` = uⁿ and `uv_rhs` = R³ + `rk3_visc` after the TDMA, `compute_ssh_rhs_ale` gives ssh_rhs = −∇·Σh(uⁿ + incr),
  and `solve_ssh_ale` solves δη/τ − gτ∇·H∇δη = that rhs. Then `update_vel` sets uⁿ⁺¹ = uⁿ + incr − gτ∇δη (θ = 1)
  and does the sync and the exchange. `compute_hbar_ale` sets `ssh_rhs_old` = I(Σh·uⁿ⁺¹) and `hbar`;
  `update_eta_n` sets `eta_n` = hbar (α = 1). This is qq's `vel_rhs_RK33` + `solve_ssh` + `update_vel_RK3`.
- u\*\* is then trimmed: u\*\*ₖ += (Σh·uⁿ⁺¹ − Σh·u\*\*)/H, so the stage-3 tracer transport carries the transport that
  changed η.

### 4. The SE block
- **Stage 1** (`se_bt_forcing_rk3`), on owned elements:
  - G_e = Σₖ helem·(3·R¹ₖ + viscₖ) + τ·(τ_s,e/ρ₀ − C_d|u_b|·u_b), where u_b = uⁿ at nlevels(e)−1. The wind and drag
    terms are the depth integral of the TDMA's boundary rows; the interior viscous fluxes telescope.
  - F_x = G_x/τ − H_e·Fx(ηⁿ) − f·sⁿ_y and F_y = G_y/τ − H_e·Fy(ηⁿ) + f·sⁿ_x, with Fx = gradient_sca·(−gηⁿ) as in
    `compute_vel_rhs` (so the two cancel to rounding) and sⁿ = Σ helem·uⁿ. This removes the 3-D Coriolis term
    exactly (D4-like, L76), with no AB2 weights.
  - `kdrag` = C_d|u_b|/H_e (with `FESOM3_SE_BOTTDRAG`); `se_ubtn` = ring level 0; F and `kdrag` are synced over the
    shared elements.
  - Then `se_subcycle` runs unchanged: M substeps and χ from `FESOM3_SE_*`, the CFL guard in `se_init` (scales with
    τ). qq's `BT_SESM_RK3` corresponds to `FESOM3_SE_VISC_AH=0`, `FESOM3_SE_BOTTDRAG=0`, χ = 0.1 and M by the guard.
- **Stage 3** (`se_rk3_finish`):
  - uⁿ⁺¹ = uⁿ + incr, trimmed: uₖ += (U^M − Σh·u)/H;
  - u\*\* trimmed to ⟨⟨U⟩⟩;
  - sync + exchange for both;
  - `ssh_rhs_old` = I(⟨⟨U⟩⟩) − W·areasvol (non-linfs);
  - `hbar_old` = hbar, `hbar` = `eta_n` = η^M on owned + halo nodes.

  Stage-3 momentum used ηⁿ: η is committed after it.

### 5. Tracers: stage formulas, the stage-3 split, LO substeps
- **Stages 1–2:** T_s·h = Tⁿ·h + τ_s·D_HO(T_{s−1}; u_{s−1}, w_{s−1}) with the full w of the stage for every tracer,
  FCT or not (D7). The elemental gradient comes from T_{s−1}. In code the update has `diff_tracers_ale`'s identity
  form, T_s = Tⁿ + (Δ + Tⁿ(hⁿ − h_s))/h_s.
  - **Constancy:** w is the continuity velocity of the same transports, so for a uniform T₀ the update is
    Δ = T₀(h_s − hⁿ) and T_s = T₀, in both stages and for every tracer, to roundoff (R5).
- **Stage 3, non-FCT:** Tⁿ⁺¹,adv = Tⁿ + τ·D_HO(T\*\*; u\*\*_tr, w_e); then the horizontal diffusion, the ALE
  reconstruct and the TDMA with Kv, the surface fluxes and w_i (`do_wimpl`). For T\*\* = T₀ the explicit step leaves
  T₀ plus the w_i part of the transport, which the TDMA takes out again (the C2 argument of `test_wimpl_tra`), so
  Tⁿ⁺¹ = T₀ (R11).
- **Stage 3, FCT:** the LO from Tⁿ with the split, the HO from T\*\* with the full w, the antidiffusive flux with the
  full w, Zalesak, then the diffusion/TDMA as for non-FCT tracers but without w_i.
  - **N = 1, the default:** today's algorithm, `do_oce_adv_tra` with `valuesAB` = T\*\* (R6). For T\*\* = T₀ the LO is
    T₀ (C2) and the antidiffusive flux is 0, so Tⁿ⁺¹ = T₀ (R11).
  - **N = 2, 3** (`FESOM3_RK3_LO_NSUB`, for a horizontal LO Courant number near 1), with h⁽ᵏ⁾ = hⁿ + (k/N)(hⁿ⁺¹ − hⁿ)
    (linfs: all hⁿ). For k = 0..N−1:

        T̃·h⁽ᵏ⁺¹⁾ = T⁽ᵏ⁾·h⁽ᵏ⁾ − (τ/N)·[div_h F_LO,h(T⁽ᵏ⁾) + δ_z(w_e T⁽ᵏ⁾)_upw]     (explicit)
        T⁽ᵏ⁺¹⁾   = implicit upwind sweep of T̃ with w_i over τ/N on h⁽ᵏ⁺¹⁾        (adv_tra_vert_impl)

    - Every substep uses the stage-3 split (f over τ), so its explicit vertical Courant number is at most maxcfl/N.
    - **Antidiffusive flux:**
      - horizontal: F_HO,h(T\*\*) − (1/N)·Σₖ F_LO,h(T⁽ᵏ⁾);
      - vertical: F_HO,v(T\*\*, w) − (1/N)·Σₖ F_LO,v(T⁽ᵏ⁾, w).

      The full w is used in the LO term, as today's driver recomputes it after the implicit step. The LO fluxes go
      in with a minus sign, then the HO fluxes are added.
    - **Limiting:** Zalesak with T_LO = T⁽ᴺ⁾ and the old field Tⁿ. Then Tⁿ⁺¹·hⁿ⁺¹ = T_LO·hⁿ⁺¹ +
      τ·div(adf_limited).
    - The substeps keep constants exactly: each explicit step goes h⁽ᵏ⁾ → h⁽ᵏ⁺¹⁾ with the full w, and the implicit
      sweep closes it (the C2 argument of `test_wimpl_tra`).
- **Stability of the unlimited quantities** (momentum, non-FCT tracers). The stage-3 explicit w_e acts on stage values
  made with the full w. Take one vertical upwind mode with the per-cell Courant number C = |w|τ/h (max CFL_z bounds
  it) and the explicit part capped at m = maxcfl: z = −C, z_e = −m, z_i = z − z_e.
  - The step multiplies the mode by A = [1 + z_e·S(z)]/(1 − z_i), with S(z) = 1 + z/2 + z²/6 the stage polynomial
    (T\*\* = S(z)Tⁿ).
  - |A| ≤ 1 up to C = 9 at m = 1 (about 3 + 6/m; 15.8 at m = 0.5). For comparison, plain RK3 without the split is
    stable to C = 2.51, and w_e in stages 1–2 (the dropped rule) at every C, at the price of an O(τ²) constancy
    defect. Checked numerically on 2026-10-28.
  - FCT tracers stay bounded at any C: the limiter keeps Tⁿ⁺¹ within the bounds of the split LO.
  - The screens record the max C (Tasks 12, 15, 21).
- **The w-split rule (D7):**

  | quantity | stage 1 | stage 2 | stage 3 |
  |---|---|---|---|
  | momentum advection | w¹ (full) | w² (full) | w_e of w³, explicit |
  | momentum implicit | — | — | w_i of w³ in `impl_vert_visc_ale` |
  | FCT tracer HO | w¹ (full) | w² (full) | w³_tr (full) |
  | FCT tracer LO | — | — | w_e, w_i of w³_tr (in every substep for N > 1) |
  | non-FCT tracer | w¹ (full) | w² (full) | w_e of w³_tr explicit, w_i in the TDMA |

  - w¹ = w(uⁿ), w² = w(u\*), w³ = w(u\*\*) before the trim, w³_tr = w(u\*\* trimmed).
  - The stage-3 split is f(CFL_z(w³, τ)) for momentum and f(CFL_z(w³_tr, τ)) for the tracers. Each is made by its
    `vert_vel_ale` call, as AB2 makes it.
  - The GM bolus is added to w and w_e after the split, as `solve_tracers_ale` does.

### 6. zstar stage geometry (Stage 6)
- Stage s = 1, 2 sets η̃_s = ηⁿ + τ_s·I(Σ helem_{s−1}·u_{s−1})/areasvol and runs `vert_vel_ale` with
  `hbar` = η̃_s, `hbar_old` = ηⁿ, dt = τ_s and **no `water_flux`**. That gives the diasurface w (w(top) = 0 by
  construction) and `hnode_new` = h_s by FESOM3's zstar law. Stage 3 passes `water_flux`, so w(top) = −W there. The law stretches all layers but the anchored deepest one, in proportion
  to the current thickness; those proportions are invariant under the law, so using the stage geometry gives the
  same h_s to rounding.
- Order within a stage: R_s on the h_{s−1} geometry; the tracers go Tⁿhⁿ → T_s·h_s with the flux thickness h_{s−1};
  then `rk3_stage_geometry(h_s)` rebuilds `helem`, `zbar_3d_n`, `Z_3d_n` and `rk3_H` (as `update_thickness_ale`,
  without committing `hnode`); then u_s is trimmed with h_s weights (Σ h_s·u_s = Σ h_s·uⁿ, `rk3.tex:82, 108`). The
  next stage's PGF (Shchepetkin), momentum and flux thickness thus see h_s.
- `hbar` bookkeeping: stage 1 sets `hbar_old` = `hbar` = ηⁿ; stages 1–2 set `hbar` = η̃_s; stage 3 restores
  `hbar` = ηⁿ before the barotropic block. The lagged `dhe` of the CG stiffness update is not touched.
- Stage 3 uses h₂ (= h^{n+1/2}) for the PGF, momentum and fluxes, and hⁿ⁺¹ from ηⁿ⁺¹ (with W) as `hnode_new`. The CG
  rhs then reads Σ h₂(uⁿ + incr), as `rk3.tex`. SE uses the depth law from the hⁿ geometry built in stage 1.
- `hbar` is restored to ηⁿ before the barotropic block. `update_thickness_ale` commits hⁿ⁺¹. The SE trim of uⁿ⁺¹ uses
  hⁿ⁺¹ and is the step's last action.

### 7. Knobs (env only)

| knob | values | default | meaning |
|---|---|---|---|
| `FESOM3_RK3` | 0/1 | 0 | the RK3 step (0 = AB2, byte-identical) |
| `FESOM3_RK3_LO_NSUB` | 1, 2, 3 | 1 | FCT low-order substeps in stage 3 (1 = today's LO with the split; 2, 3 for a horizontal LO Courant number near 1) |
| `FESOM3_RK3_CHECK` | 0/1 | 0 | per-step `RK3_CHECK` line |
| `FESOM3_RK3_CHECK_TOL` | real ≥ 0 | 0 | stop when an `RK3_CHECK` value exceeds it (0 = report only) |
| `FESOM3_SSH_SE` + `FESOM3_SE_*` | existing | 0 | 1 = RK3 + SE, 0 = RK3 + CG |

The `FESOM3_RK3_*` knobs are read only when `FESOM3_RK3=1`; any value outside its range stops the run. RK3 also stops
with zlevel, under single precision, with cavities, and without `rk3_init`.

### 8. Restart
- RK3 reads only the state: uv, eta_n, hbar, hnode, T/S `values`, `d_eta` (the CG initial guess), TKE, and the SE
  rings (`se_eta1/2`, `se_ubt0..2`). The AB stores (`urhs_AB`, `vrhs_AB`, `<tr>_AB`, `<tr>_M1`, `se_sbar_old`) are
  still written, never read.
- `checkpoint.json` gets `"time_scheme": "rk3"`, only from an RK3 run.
- AB2 resuming an `rk3` checkpoint: lfirst on the first step, `valuesold(1) = values`, `uv_rhsAB = 0`, and with SE
  `se_sbar_old = 0`. lfirst sets only a2 = 1; the a1·`se_sbar_old` term stays, so a cold start relies on the zero.
  RK3 resuming an AB2 checkpoint: nothing to do.
- Exactness: RK3 is self-starting, so split = straight (max|Δ| = 0) with the existing gates. zstar CG needs
  `FESOM3_RESTART_ZSTAR_EXACT=1`, as AB2 does (L73/L78).

### 9. Communication per step (linfs)
- **Per stage:**
  - `exchange_nod(w)`;
  - per tracer, `exchange_elem_full(tr_xy)` + `exchange_nod(valuesAB)`;
  - the momentum exchanges of the advection scheme;
  - the shared sync and `exchange_elem(rk3_us)`.
- **Once:** the viscosity's `exchange_elem(U_c/V_c)`.
- **Stage 3 adds:**
  - the CG solve (reductions) or the M SE substeps (2-D exchanges);
  - the u\*\* trim sync and its exchange;
  - the second `exchange_nod(w)`;
  - for N > 1 only: N − 1 extra `exchange_nod` per FCT tracer;
  - the FCT's `exchange_nod(fct_plus/minus)`.

Roughly three times AB2's 3-D halo traffic. Measured in Task 21.
